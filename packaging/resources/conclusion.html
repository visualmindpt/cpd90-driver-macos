Installation complete · Instalação concluída

English: install Mitsubishi's ICC profiles with sudo /Library/Printers/CPD90Universal/instalar-perfis.sh <download>, add the printer in System Settings (driver "MITSUBISHI CP-D90D Universal"), and see the README for Lightroom, Quick Actions, cpd90-print and iPhone printing.

Perfis ICC: instale os perfis da Mitsubishi com sudo /Library/Printers/CPD90Universal/instalar-perfis.sh <download>.

Mudar as filas existentes para o driver novo (mantém as predefinições de cada fila). No Terminal, primeiro veja o que vai mudar:

/Library/Printers/CPD90Universal/migrar-filas.sh

e depois aplique:

sudo /Library/Printers/CPD90Universal/migrar-filas.sh --aplicar

Para voltar ao driver da Mitsubishi (enquanto estiver instalado):

sudo /Library/Printers/CPD90Universal/migrar-filas.sh --reverter --aplicar

Imprimir a partir do Finder: selecione fotos, clique com o botão direito › Ações Rápidas › Imprimir na CP-D90 (15×20), (10×15) ou as versões mate. Se ainda não aparecerem, termine a sessão e volte a entrar.

iPhone/iPad (AirPrint): requer brew install cups; depois:

/Library/Printers/CPD90Universal/airprint/airprint.sh ativar "CP-D90 (iPhone)"

Impressão direta (tamanho exato, perfil ICC):

/Library/Printers/CPD90Universal/bin/cpd90-print --ajuda

Desinstalar:

sudo /Library/Printers/CPD90Universal/desinstalar.sh
